# Playwright Learning

This repository contains small JavaScript examples organized by topic. The examples are standalone scripts for learning and practice.

## Topics

- `chapter_02_JavaScript_Concepts/` — introductory JavaScript examples
- `chapter_05_Operator/` — data types, assignment, arithmetic, comparison, and logical operators

## Run an example

Install [Node.js](https://nodejs.org/) and run a script from the repository root:

```sh
node chapter_02_JavaScript_Concepts/01_HelloWorld.js
```

Replace the script path with any example you want to run.
